# Serving dependencies only — this is what the Space installs.
#
# The repo's own requirements.txt is a superset: it also carries the training
# and evaluation stack (beir, pytrec-eval-terrier, wandb, peft, onnx,
# onnxruntime, anthropic), none of which the serving path imports. Two reasons
# to leave them out rather than reuse that file:
#
#   pytrec-eval-terrier compiles C at install time, and a Space build has no
#   reason to risk failing on a toolchain it only needs for offline evaluation;
#   and every package here is downloaded on each rebuild, so the shorter list is
#   also the faster, more reliable build.
#
# torch is pinned to 2.8.0 because ZeroGPU — the only hardware a free personal
# account may run a Gradio Space on — supports 2.8.0 and above and rejects the
# 2.6.0 the rest of the project pins. Nothing here touches the GPU (see
# app.py), but the runtime still inspects torch at import.
